# Material Request

**College thesis · Doddie Prawarjito**

## Problem

A workflow application for submitting project materials, approving requests, and recording warehouse fulfilment.

## Contribution

The author reports implementing the complete project. Third-party libraries, UI foundations, and historical academic credits retain their attribution. This case study makes no claim about business impact without measured evidence.

## Design and engineering

The implementation separates master data, requests, and administration, with relational models and route permissions. Item-level fulfilment lets a request progress across multiple deliveries.

## Current limits

Seeded data and accounts are for local demonstrations. The application needs a broader review of object-level access and concurrent updates before public deployment.

## Demonstration

Log in, inspect a request, follow approval and partial fulfilment, and show the resulting warehouse history.

The README describes setup. Validation results from this preparation are recorded in the local portfolio preparation report; feature descriptions alone are not test evidence.
